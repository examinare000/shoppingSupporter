# ADR-003: Playwrightによるスクレイピングの採用

## ステータス
承認済み

## 背景
現代のECサイトはJavaScriptによる動的なレンダリングが多く、単純なHTMLパーサー（BeautifulSoupのみ等）では正確な価格やポイント情報を取得できないケースが増えている。

## 決定
スクレイピングエンジンとして Playwright (Python) を採用する。

## 理由
- **動的コンテンツへの対応**: ブラウザをシミュレートするため、JavaScript実行後のDOMを取得可能。
- **堅牢性**: セレクタの待機処理などが組み込まれており、ネットワーク遅延に強い。
- **デバッグ容易性**: ヘッドレスモードを解除してブラウザの動作を目視で確認できる。

## 影響
- コンテナのイメージサイズが大きくなる（ブラウザバイナリが必要なため）。
- 実行速度が通常のHTTPリクエストより遅くなるため、キューイングなどの非同期処理が必須となる。

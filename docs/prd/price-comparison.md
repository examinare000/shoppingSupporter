# 商品実質価格比較機能 (Price Comparison) 要件定義書

## 概要
Amazon・楽天・Yahoo! ショッピングの 3 大 EC サイトを横断し、送料・ポイント還元を加味した「実質価格」で商品を比較・検討できるサービスを提供する。

## 背景
現代のオンラインショッピングにおいて、表示価格だけでは本当の安さを判断できない。特にポイント還元率はユーザーの属性（カード保有、会員ランク、サブスク加入状況）に強く依存し、手計算での比較は困難である。本プロジェクトは、この「計算の複雑さ」を解消し、ユーザーが最小のコストで最適な購入決定を行えるようにすることを目的とする。

## 機能要件

### 1. 商品検索と横断比較
- JAN コードまたはキーワードによる商品検索。
- 複数サイト（Amazon, 楽天, Yahoo）からの同時価格・在庫取得。
- 送料込み、ポイント差し引き後の「実質価格」の自動算出と表示。

### 2. パーソナライズされた実質価格
- ユーザー属性（楽天ランク、Amazon Prime 有無、Yahoo プレミアム有無等）の登録。
- 所有クレジットカード情報の登録（基本還元率、サイト別特定倍率）。
- 属性に基づいたサイト別獲得ポイントの動的計算。

### 3. 商品画像とサイト優先度
- 複数サイトから取得した画像のうち、ユーザーが好みのサイトの画像を優先的に表示する設定。
- 画像が欠落している場合のフォールバック表示。

### 4. 価格推移と買い時アドバイス (将来)
- 過去の価格履歴の蓄積とチャート表示。
- 定期セール時期を考慮した「買い時」の提示。

## 非機能要件

### 1. デザイン性 (Editorial Design)
- 従来の EC 比較サイトのような「バナーだらけの賑やかさ」を排除し、新聞や雑誌のような落ち着いた、精緻なエディトリアルデザインを採用する。
- 活字の美しさと情報の読みやすさを最優先する。

### 2. パフォーマンス
- サーバーレス環境（Vercel）において、コールドスタートの影響を最小限に抑える。
- 検索クリティカルパスにおいて、公式 API の遅延をユーザーに直接見せない（DB キャッシュ/Cron 主導）。

### 3. 正確性
- 各 EC サイトの最新の還元ルール（SPU 等）を可能な限り正確に反映する。
- 算出根拠（内訳）をユーザーが確認できるようにする。

## 受け入れ基準

| シナリオ | 条件 | 実行 | 結果 |
|---|---|---|---|
| ゲスト検索 | 未ログイン状態 | 商品を検索する | デフォルトの還元率（1%）に基づいた実質価格が表示される |
| ログイン検索 | 楽天ダイヤモンド会員としてログイン | 楽天の商品を含む検索 | 楽天 SPU 加算が反映された高いポイント還元と、それに基づく実質価格が表示される |
| 画像優先度変更 | 設定で「Amazon」を最優先に設定 | 商品一覧を表示 | 出品に Amazon がある場合、Amazon の商品画像がメインで表示される |
